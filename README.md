# time-budget-app

1日24時間を先に配分し、起床から積み上げて管理する時間予算管理アプリ（iPhone向けPWA）。

不規則な生活でも、自分が大切にしたい活動の時間を確保するためのもの。

## 状態

- 仕様書: [時間予算管理アプリ_仕様書_v1.2.md](./時間予算管理アプリ_仕様書_v1.2.md)
- 実装: 未着手

## 方針（要約）

- 午前0時ではなく、起床を1日の起点にする
- 睡眠も24時間予算の一部
- 各カテゴリーはストップウォッチ型（超えてよい）かタイマー型（絞りたい）
- 催促・警告・カウントダウンはしない。積み上がった実績を正直に見せる
- v0.1はサーバーなし、端末内保存、通知なし

詳細と出どころ（ユーザー要望／合意／決定／保留）は仕様書を参照。
