# time-budget-app

1日24時間を先に配分し、起床から積み上げて管理する時間予算管理アプリ（iPhone向けPWA）。

不規則な生活でも、自分が大切にしたい活動の時間を確保するためのもの。

## 状態

- 仕様書: [時間予算管理アプリ_仕様書_v1.2.md](./時間予算管理アプリ_仕様書_v1.2.md)
- 実装の指示書: [docs/v0.1-brief.md](./docs/v0.1-brief.md)
- 実装: **v0.1**（仕様書 §16 の 1〜9）

## 方針（要約）

- 午前0時ではなく、起床を1日の起点にする
- 睡眠も24時間予算の一部
- 各カテゴリーはストップウォッチ型（超えてよい）かタイマー型（絞りたい）
- 催促・警告・カウントダウンはしない。積み上がった実績を正直に見せる
- v0.1はサーバーなし、端末内保存、通知なし

詳細と出どころ（ユーザー要望／合意／決定／保留）は仕様書を参照。

## ローカルでの起動方法

Node.js 22 以降が入っている前提です。

```sh
npm install
npm run dev
```

表示された URL（例: `http://localhost:5173/time-budget-app/`）をブラウザで開きます。
スマホの見た目で確かめるときは、ブラウザの開発者ツールで「モバイル表示」にしてください。

そのほかのコマンド:

```sh
npm test        # 計測ロジック・保存のテスト
npm run build   # 公開用ファイルを dist/ に作る
npm run preview # dist/ をローカルで確認する
```

## 公開方法（GitHub Pages）

main ブランチに push されると、GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして GitHub Pages に公開します。
最初に一度だけ、GitHub のリポジトリ画面で次の設定をしてください。

1. リポジトリの **Settings** を開く
2. 左の **Pages** を選ぶ
3. **Source** を **GitHub Actions** にする

公開先は `https://<GitHubのユーザー名>.github.io/time-budget-app/` です。
（Vite の `base` は `/time-budget-app/` にしてあります。リポジトリ名を変えるときは `vite.config.ts` と `index.html` の `/time-budget-app/` も変えてください。）

## iPhone での使い方

1. Safari で公開先の URL を開く
2. 画面下の **共有**（四角から矢印が出ているアイコン）をタップ
3. **ホーム画面に追加** を選ぶ
4. 以後は **ホーム画面のアイコンから** 開く

ホーム画面に追加したアプリと Safari とでは、データの保存先が別になります。
**最初からホーム画面のアイコンから使ってください**（Safari で記録したものはアプリ側には出ません）。

一度開いたあとはオフラインでも動きます。データは端末の中にだけ保存されるので、記録タブの「JSONを書き出す」でときどきバックアップしてください。

## 使い方の流れ

1. 起きたら「今日を開始」。ここから1日（サイクル）が積み上がります。
2. カードをタップで計測を開始・停止。別のカードをタップすると前の計測は自動で止まります。長押しで「ながら」の同時計測。
3. 寝るときは一番下の「睡眠」カードをタップ（就寝）。起きたら「起床（今日を開始）」。昼寝なら「仮眠だった」。
4. 就寝を押し忘れて寝たときは、画面上の日付をタップ →「今日を開始（就寝を押し忘れたとき）」で就寝時刻を入力。
5. 予算は「配分」タブで。今のサイクルの予算と、次回から使うテンプレートを分けて編集できます。
6. 「記録」タブでサイクルごとの予算と実績、計測記録の修正ができます。

## 実装済み機能（v0.1）

- カテゴリーの作成・編集・並び替え・アーカイブ、計測モード（ストップウォッチ型／タイマー型）、優先して守る
- 予算の設定（テンプレート1つ、未配分の表示、24時間超の警告）。サイクル開始時にテンプレートからコピー

- 配分画面（ドーナツグラフ、予算の編集）
- 記録タブ（サイクル一覧と詳細、カテゴリー別の予算と実績、境界をまたぐ記録の自動付け替え）
- IndexedDB 保存、永続保存の要求、JSON の書き出し・読み込み（上書き）、7日たったらバックアップの促し
- PWA（ホーム画面に追加、オフライン動作、「新しいバージョンがあります」の表示）
- 計測・集計ロジックの自動テスト（`npm test`）

## 仕様への質問・実装上の判断

仕様書で決まっていなかった点は、次のように判断しました。使ってみて違えば変えます。

- **初めての「今日を開始」では就寝時刻を聞かない。** まだ記録が何もないときに「昨夜は何時に寝ましたか」と聞いても意味がないため。2回目以降は、睡眠の計測が動いていなければ聞きます。「寝ていない」も選べます。
- **ストップウォッチ型のカードは、目標に届くまでは「計測済み / 予算」の数字だけを見せる。** 「あと○分」の文言は催促に近いので出していません。目標到達後は「目標到達 +0:30」と肯定的に表示します。
- **タイマー型は「残り ○:○○」→ 尽きたら「超過 ○:○○」**と中立に表示します。
- **睡眠の記録は、開始時刻が属するサイクルに全量入れる。** 起床時刻を睡眠の終了より少し前に修正しても分割しません（仕様 §14.2 の「睡眠は分割しない」を優先）。
- **起床時刻を修正すると、その起床で終わった睡眠記録の終了時刻も一緒に動きます。**（睡眠と起床は同じ瞬間なので）
- **分の表示は四捨五入。** 秒の端数で「2:59」と見えるのを避けるため。
- **「止め忘れ」で「そのまま続ける」を選ぶと、アプリを閉じて開き直すまで同じ計測については聞きません。**
- **JSON の読み込みと「すべての記録を消去」だけは確認画面を出します。** 取り消しができない操作のため。
- **タイムゾーンはすべて UTC で保存し、表示だけ端末の時刻に合わせています。**
